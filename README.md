# OzonAccess

OzonAccess — бесплатное расширение Manifest V3 для Chrome и Edge. Оно улучшает семантическую структуру главной страницы Ozon: добавляет ориентиры, заголовки названий товаров, имена подтверждённых кнопок и безымянных товарных ссылок. Визуальный интерфейс, ссылки и обработчики сайта не заменяются.

Проект ориентирован на клавиатуру и NVDA, но не заявляет полное соответствие WCAG 2.2 AA. Результаты анализа сохранённой страницы находятся в [docs/audit.md](docs/audit.md).

## Требования и команды

Нужны Node.js 20.19+ и npm.

```powershell
npm install
npm run typecheck
npm run lint
npm test
npm run build
```

Для браузерной проверки fixture:

```powershell
npx playwright install chromium
npm run test:e2e
```

Глубокий аудит Chromium/CDP и сравнение до/после:

```powershell
npm run audit:fixture
npm run audit:compare
npm run audit:live
```

Безопасностные ограничения и режим проверки подсказок поиска описаны в [tools/audit/README.md](tools/audit/README.md). Текстовые результаты находятся в `reports/`.

Готовое распакованное расширение создаётся в `dist/`; `manifest.json` лежит в его корне.

## Установка

Chrome: открыть `chrome://extensions`, включить «Режим разработчика», выбрать «Загрузить распакованное расширение» и указать папку `dist`.

Edge: открыть `edge://extensions`, включить «Режим разработчика», выбрать «Загрузить распакованное расширение» и указать `dist`.

Для обновления выполнить `npm run build`, затем нажать «Обновить» на карточке расширения. Пользовательский интерфейс и дополнительные разрешения не требуются; скрипт работает только на `ozon.ru` и `www.ozon.ru`.

## Ограничения

- Правила подтверждены сохранённым DOM и требуют ручной проверки на текущем Ozon с NVDA.
- Неопознанные кнопки не получают фиктивных подписей и перечисляются в консольной диагностике.
- Случайные CSS-классы Ozon не используются как единственный источник смысла, однако изменение `data-widget` или структуры карточек может потребовать обновления правил.
- Расширение ничего не отправляет на внешние серверы и не изменяет корзину, заказы, оплату или состояние аккаунта.
