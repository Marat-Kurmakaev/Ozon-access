# Проверка кликабельных элементов

Дата: 2026-11-04.

## Кнопка входа

`div[data-widget="profileMenuAnonymous"][tabindex]` — единственный ненативный фокусируемый контрол в сохранённом DOM. Fixture не выполняет JavaScript Ozon и поэтому ошибочно показывал его как generic без имени.

Live-проверка пользователя подтвердила, что исходный элемент нормально озвучивается и работает. Добавленные OzonAccess роль, имя и клавиатурный обработчик ломали штатную механику. Правило полностью удалено: расширение больше не изменяет `profileMenuAnonymous`.

## Другие потенциально кликабельные элементы fixture

Среди фокусируемых ненативных элементов других экземпляров нет. Pointer-cursor без собственного фокуса массово встречается на вложенных узлах карточек (`span`, `div`, `svg`, `path`, `img`), но они находятся внутри нативных ссылок и кнопок. Добавление им `tabindex` или роли создало бы лишние дублирующие остановки Tab.

Нативные `a`, `button`, `input`, `select`, `textarea` сохраняют собственное клавиатурное поведение. Подтверждённые безымянные нативные элементы исправляются отдельными правилами: фотографии, избранное, фильтры и корзина.

## Ограничение live-проверки

Встроенный браузерный API был отключён настройками Work, а окно Chrome было свёрнуто и не предоставило проверяемый DOM. Решение основано на подтверждённой пользователем live-регрессии: расширение полностью прекращает вмешиваться в элемент входа. После обновления расширения страницу нужно перезагрузить, чтобы удалить атрибуты старого content script из текущего DOM.
