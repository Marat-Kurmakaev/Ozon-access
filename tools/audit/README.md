# Инструмент глубокого аудита

Анализатор запускает Chromium и использует Playwright ARIA snapshots, CDP Accessibility API, сведения CDP о прямых и родительских обработчиках и axe-core. Упрощённая функция имени расширения не используется как источник вычисляемой роли или имени.

## Команды

```powershell
npm run audit:fixture
npm run build
npm run audit:compare
npm run audit:live
npm run audit:groups -- --groups=element-group-008,element-group-009,element-group-012
```

`audit:fixture` не выполняет скрипты из `ozon-dom.html` и блокирует внешнюю сеть. Основные отчёты записываются в `reports/`.

`audit:compare` исследует fixture до и после подключения `dist/content.js`; результат находится в `reports/compare/`.

`audit:live` открывает главную страницу Ozon в новом временном неавторизованном профиле, фиксирует загрузку, стабилизацию и безопасную прокрутку. Профиль удаляется после завершения. Блокировка или неполная загрузка записывается в отчёт, защита сайта не обходится.

`audit:groups` берёт SVG-сигнатуры указанных `--groups` из fixture-отчёта и сохраняет только один репрезентативный живой элемент каждой группы в `reports/live-groups/`. По умолчанию режим полностью пассивный. Отдельный `npm run audit:groups:arrows` разрешает единственное проверочное нажатие каждой стрелки и блокирует переход по товарной ссылке; запуск этой команды является явным разрешением взаимодействия. Кнопки избранного этот режим не нажимает.

Для явно разрешённой проверки подсказок поиска без отправки формы:

```powershell
npm run audit:behavior
```

Даже в этом режиме неизвестные элементы, вход, корзина, избранное, покупка, заказ, оплата и удаление данных автоматически не нажимаются.

Каталог включает нативные элементы управления, ссылки, ARIA-роли, фокусируемые и потенциально кликабельные элементы, а также ориентиры и заголовки. Открытые shadow roots и доступные same-origin iframe обходятся рекурсивно. Cross-origin iframe фиксируются только в доступной Chromium части дерева.
